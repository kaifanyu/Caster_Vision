# Input data slots

- `camera_calibration/`: checkerboard images from the caster camera.
- `swivel/clip.mp4`: a swivel-caster run (or update the config path).
- `ball/clip.mp4`: the matched ball-caster run.
- `car_tracks/track.csv`: `t,x,y,theta` plus optional `vx_world,vy_world,omega`.

Large recordings and generated frames are ignored by Git.
