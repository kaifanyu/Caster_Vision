# Ball-axis calibration clips go here

Add `pure_roll.mp4` and `pure_swivel.mp4`. Start both clips from the same marked
home pose used for measurement. In the default sign convention, move only in
the positive ball-x direction for pure roll and only in positive ball-z for
pure swivel. If a clip moves in the negative direction, pass the corresponding
`--roll-sign -1` or `--swivel-sign -1` option.
